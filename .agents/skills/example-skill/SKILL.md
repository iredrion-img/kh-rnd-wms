# Example Skill

이 폴더는 클로드(Claude)가 특정 워크플로우나 도구를 어떻게 사용해야 하는지 알려주는 '스킬(Skill)'입니다. 
에이전트는 이 `SKILL.md` 문서를 읽고 명시된 규칙과 가이드라인을 따르게 됩니다.

## 사용 방법 (How to use)
1. 새로운 스킬을 만들려면 `.agents/skills/[스킬-이름]/` 폴더를 만들고 그 안에 `SKILL.md`를 작성하세요.
2. 상단의 YAML 헤더(`name`, `description`)를 반드시 기입하세요.
3. 클로드에게 특정 스킬을 사용해달라고 요청하거나, 클로드가 관련 작업을 수행할 때 자동으로 이 스킬을 참조하게 됩니다.

## 추가 파일들
이 폴더 안에는 스킬 실행에 필요한 파이썬 스크립트, 쉘 스크립트, 또는 추가 참조 문서들을 함께 보관할 수 있습니다.
에이전트는 필요한 경우 이 폴더의 스크립트들을 직접 실행하여 스킬을 수행합니다.
